# 🤖 AI Interview Agent

A full-stack AI-powered interview preparation platform that helps candidates practice realistic interviews using their resume and receive personalized interview questions, feedback, and performance insights.

The project combines **React, Node.js/Express, MongoDB, AI integration, Razorpay payment gateway, and cloud deployment** to provide an interactive interview preparation experience.

## 📌 Project Overview

The objective of this project is to provide an AI-powered platform for practicing job interviews in an interactive environment.

Users can upload their resume, configure an interview, and interact with an AI interviewer that generates relevant questions based on the candidate's profile.

The application also analyzes the interview and presents performance insights through an interactive dashboard.

Key functionalities include:

- Resume upload and processing
- AI-generated interview questions
- Resume-based interview questions
- Interactive AI interview
- Follow-up questions
- AI-based response evaluation
- Interview performance analysis
- Performance dashboard
- User authentication
- Razorpay payment integration
